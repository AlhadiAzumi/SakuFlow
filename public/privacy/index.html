Kebijakan Privasi Sakunode

Sakunode adalah aplikasi pencatat keuangan berbasis web dan bot WhatsApp yang membantu kamu melihat ke mana uang pergi. Dokumen ini menjelaskan data apa yang kami kumpulkan, cara kami memakainya, dan hak kamu atas data tersebut.

Terakhir diperbarui: 26 November 2026

1. Data yang kami kumpulkan

  • Akun: alamat email dan data autentikasi. Kami tidak menyimpan kata sandi kamu. Autentikasi dikelola oleh Supabase Auth.
  • Login Google: nama tampilan, email, dan informasi profil dasar dari akun Google kamu.
  • Data keuangan: jenis transaksi, nominal, kategori, tanggal, catatan opsional, batas budget, dan target tabungan.
  • WhatsApp: nomor telepon, kode verifikasi, isi pesan yang kamu kirim ke bot, dan ID pesan untuk mencegah pemrosesan ganda.
  • Perangkat: pada mode lokal, data tetap disimpan di browser kamu sendiri.

Data email dan profil Google yang kamu berikan hanya dipakai untuk autentikasi akun Sakunode, yaitu membuat atau mengenali akunmu. Kami tidak memakainya untuk iklan, profil pemasaran, atau membagikannya kepada pihak ketiga.

2. Cara kami memakai data

Data dipakai untuk menampilkan ringkasan dan visualisasi alur uang, menyinkronkan catatan antarperangkat, menghubungkan nomor WhatsApp ke akun, menjawab perintah seperti ringkasan dan bantuan, serta mengirim kuitansi konfirmasi transaksi.

3. Penyimpanan dan pihak ketiga

Data disimpan di Supabase. Pesan WhatsApp diproses melalui Meta WhatsApp Cloud API. Verifikasi keamanan login memakai Cloudflare Turnstile. Kami tidak menjual atau menyewakan data kamu untuk iklan. Kunci akses server hanya tersimpan di server bot dan tidak pernah dikirim ke browser.

4. Keamanan

Akses data dibatasi dengan Row Level Security sehingga hanya pemilik akun yang dapat membaca dan mengubah datanya. Percobaan masuk dibatasi 7 kali gagal per 30 menit. Webhook WhatsApp diverifikasi dengan tanda tangan HMAC-SHA256.

5. Retensi dan penghapusan

Data disimpan sampai kamu menghapusnya. Kamu bisa mengunduh data dalam bentuk Excel dan menghapus data lokal melalui menu Setelan. Untuk penghapusan data cloud permanen, hubungi kami lewat email di bawah. Kode verifikasi dihapus setelah berhasil dipakai.

6. Hak kamu

Kamu berhak mengakses, mengubah, mengunduh, atau meminta penghapusan data pribadi. Kirim permintaan ke alamat email di bawah.
